# Итоговый тест: Оказание первой помощи

SPA (Single Page Application) для прохождения итогового теста по курсу «Первая помощь без мифов и паники». 
Результаты сохраняются в Google Таблицу через Google Apps Script.

## Особенности теста
*   **Банк вопросов:** 43 вопроса, составленных на основе актуальной лекции и требований Минздрава РФ.
*   **Рандомизация:** При каждом запуске теста система случайным образом выбирает 20 вопросов из 43. Варианты ответов внутри каждого вопроса также перемешиваются.
*   **Обучающий режим:** После выбора ответа тест не переходит сразу к следующему вопросу. Появляется подробное объяснение (почему этот ответ верный или неверный), а правильные/неправильные варианты подсвечиваются цветом.
*   **Множественный выбор:** Если в вопросе несколько правильных ответов, система автоматически покажет квадратные чекбоксы вместо круглых радиокнопок.
*   **Кроссбраузерность:** Полностью адаптивный интерфейс для ПК, планшетов и смартфонов.

## Быстрый старт

1.  Скопируйте все 4 файла (`index.html`, `styles.css`, `app.js`, `README.md`) в папку вашего проекта.
2.  Настройте Google Apps Script для сохранения результатов (см. инструкцию ниже).
3.  Вставьте полученный URL в файл `app.js` в переменную `GOOGLE_SCRIPT_URL`.
4.  Откройте `index.html` в браузере (рекомендуется использовать локальный сервер, например, расширение Live Server в VS Code, чтобы избежать возможных CORS-ошибок при тестировании).

## Настройка Google Apps Script (Сохранение результатов)

### Шаг 1. Создайте НОВУЮ Google Таблицу
1. Перейдите на [sheets.google.com](https://sheets.google.com) и создайте новую таблицу.
2. В первой строке добавьте заголовки для столбцов (это поможет вам потом фильтровать данные):
   `Дата | ФИО | Организация | Должность | Подразделение | Дата рождения | Дата трудоустройства | Правильных | Результат | Статус`

### Шаг 2. Откройте Apps Script
1. В меню вашей таблицы выберите: **Расширения → Apps Script**.
2. Удалите весь существующий код в редакторе.

### Шаг 3. Вставьте код (Code.gs)
Скопируйте и вставьте следующий код в редактор Apps Script:

```javascript
function doPost(e) {
  try {
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    const data  = JSON.parse(e.postData.contents);

    // Добавляем новую строку с результатами
    sheet.appendRow([
      new Date(),
      data.fullName,
      data.organization,
      data.position,
      data.department,
      data.birthDate,
      data.hireDate,
      data.correctAnswers,
      data.percent + '%',
      data.passed ? 'Сдал' : 'Не сдал'
    ]);

    return ContentService
      .createTextOutput(JSON.stringify({ status: 'success' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'error', message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
